`mould` is a lightweight, single-binary dynamic database, authentication, and background job processing engine written in Go. Inspired by PocketBase and Elixir's Oban, Moul consolidates everything needed to build modern applications into a single portable binary.

<Callout type="info">
  **Single Binary Philosophy**: No Docker orchestration or microservice sprawl required. Run dynamic SQLite schema management, multi-factor authentication, background job queues, first-party analytics, and real-time Server-Sent Events with zero external dependencies.
</Callout>
