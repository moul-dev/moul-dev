# Moul Admin (Lit)

This is an experimental rewrite of the Moul Admin Console using Lit.

## Tech Stack
- [Lit](https://lit.dev/) for web components
- [@lit-labs/router](https://www.npmjs.com/package/@lit-labs/router) for routing
- [@lit/task](https://lit.dev/docs/data/task/) and [@lit-labs/signals](https://github.com/lit/lit/tree/main/packages/labs/signals) for data fetching and state
- [Vite](https://vitejs.dev/) for build tooling

## Development

Install dependencies: `npm install`
Start development server: `npm run dev &`
Build for production: `npm run build`
