# Changelog: August 2026

Recent updates focus on operational stability, schema migrations, query performance, and zero-config deployment primitives for the `moul-dev` engine and `moul` console.

## Core Updates

### 1. Installation & In-Place Self-Updates
- **`install.sh`**: Single command installer script for downloading precompiled `moul` and `moul-dev` release binaries.
- **`moul update` & `moul-dev update`**: Self-update CLI subcommand to fetch, verify, and atomically swap binaries from GitHub releases.

### 2. Dynamic Schema Sync & Validation
- **`SyncMoulTableColumns`**: Safe non-destructive column additions via SQLite PRAGMA table inspection.
- **Field Types & Relations**: Support for `Select/Enum` field types and strict relation field integrity checks.
- **Timestamp Standardization**: Standardized `created_at` and `updated_at` handling across all Mouls.

### 3. Server-Side Data Engine & Webhooks
- **Cursor-Based Pagination**: High-performance key-based pagination on `ListRecords` to eliminate offset query overhead.
- **Server-Side Filtering & Sorting**: Evaluates query criteria directly on the database engine.
- **Event Webhooks**: Outbound HTTP notifications on record `create`, `update`, and `delete` events.

### 4. Operations & Infrastructure
- **Automatic TLS (CertMagic)**: Native Let's Encrypt certificate acquisition and renewal for zero-config HTTPS.
- **System Monitoring**: Native Go system monitoring for CPU, memory, disk, and goroutine telemetry.
- **Feature Flags**: Built-in feature flag state management controllable via TUI.
