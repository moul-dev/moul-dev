# Changelog: September 2026 (v2026.09)

This release introduces an embedded Web Admin Console compiled directly into the single Go binary, real-time record subscriptions via Server-Sent Events (SSE), full-fidelity data import and export (CSV & JSON), extended field types, and a unified binary naming architecture (`moul` daemon and `moul-ctl` TUI).

## Highlights & Major Additions

### 1. Embedded Web Admin Console (`ui/`)
- **Single-Binary Web Console**: Compiled directly into `moul` using Go `embed`, accessible at `/_moul_/` (with automatic redirects from `/admin`) without external web server dependencies.
- **Moul UI & React Aria Components**: Built with `@moul-dev/ui` (React Aria Components + StyleX) for accessible keyboard navigation, responsive forms, and interactive data tables.
- **Tri-State Theme System**: Automatic OS preference synchronization with system, light, and dark modes, persisted in local storage.
- **Record Detail Drawers & Accessible Dialogs**: Side drawer interface for fluid record inspection and inline editing, alongside accessible alert dialogs for destructive actions.
- **Mobile-Friendly Layout**: Responsive layout with touch-friendly drawer navigation, mobile data views, and adaptive tables.
- **Interactive Monitoring & Settings**: Live background worker queue dashboard, feature flag management, system telemetry graphs, dynamic settings hot-reloading, and root password updates.

### 2. Real-Time Record Subscriptions (SSE)
- **Native SSE Hub**: In-memory, lock-optimized Server-Sent Events engine (`internal/realtime`) delivering low-latency push notifications without Redis or external message brokers.
- **Granular Event Subscriptions**: Clients can subscribe to global (`/api/moul/subscribe`) or collection-specific (`/api/moul/:name/subscribe`) record mutations (`create`, `update`, `delete`) with server-side filter evaluation.
- **Access Rule Security**: SSE streams respect collection `subscribeRule` expressions to ensure data privacy at the protocol level.
- **Real-Time Event Stream Inspector**: Dedicated live event streaming view in the Web Admin Console (`/_moul_/realtime`) to observe database mutations and payloads as they happen.

### 3. Data Portability: Import & Export
- **CSV & JSON Support**: Full-fidelity export and import for all Moul collections, supporting RFC 4180 CSV and JSON envelope formats.
- **Configurable Conflict Handling**: Multi-strategy import resolution supporting `upsert`, `insert`, and `replace` modes with transactional integrity or continue-on-error options.
- **Multi-Record Selection**: Batch record selection in the Web Admin Console for bulk export and deletion.

### 4. Schema Engine & Extended Field Types
- **Rich Field Types**: First-class support for rich text, file attachments with preview handling, relational foreign keys, and select/enum types.
- **Data Retention & Periodic Pruning**: Built-in automated retention tasks to prune completed worker jobs, expired sessions, and historical request logs.
- **Hardened Authentication**: Enhanced Apple OAuth2 verification flow with dynamic JWT secret generation.

### 5. Architectural Clarification & Tooling
- **Binary Naming Refactor**: Clarified executable boundaries—`moul` serves as the unified daemon and API engine (`cmd/moul`), while `moul-ctl` serves as the terminal management TUI (`cmd/moul-ctl`).
- **Telemetry Streamlining**: Fully migrated host monitoring to native in-process Go sampling, removing the Telegraf dependency.
- **Tooling & Stability**: Upgraded toolchain to Go 1.26.5, achieved zero `golangci-lint` issues, and resolved concurrency races in test suites.

### 6. Documentation & Internationalization
- **Static Site Generation (SSG)**: Pre-rendered documentation site (`website/`) for instant page loads.
- **Khmer Translation (i18n)**: Added complete Khmer documentation (`/km`) with optimized font rendering and typographic hierarchy.
- **Production Guides**: Detailed production runbooks for bare-metal LXD container deployments with Tailscale and Cloudflare Tunnels.
