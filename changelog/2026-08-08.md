# Changelog: August 8, 2026 (v2026.08.08)

This release expands `mould` (formerly `moul-dev`) from a standalone engine into an extensible Go application framework, adds native Model Context Protocol (MCP) server integration for AI tools, introduces OAuth2 social login providers, and refines SQLite schema migration primitives.

## Highlights & Major Additions

### 1. Extensible Go Application Framework (`pkg/app`)
- **Custom Worker Handlers (`app.RegisterWorker`)**: Register custom Go task functions directly into the SQLite-backed Oban queue engine.
- **Custom HTTP Route & Middleware Hooks (`app.OnBeforeServe`, `app.Router`)**: Mount custom Echo routes and middleware directly on the embedded web server without modifying core engine source code.
- **Embeddable Daemon Architecture**: Refactored `cmd/mould` around `pkg/app`, allowing developers to import `mould` as a library in standard Go applications.

### 2. Built-In Model Context Protocol (MCP) Server & AI-Native Docs
- **Native MCP Server Endpoint**: Serves MCP protocol tools over HTTP (`/mcp`) and stdio transport, giving AI assistants direct tools to inspect Mouls (collections), query records, check worker status, manage feature flags, and read system telemetry.
- **Binary-Embedded AI Documentation**: Serves `llms.txt`, `llms-full.txt`, and `AGENTS.md` directly from `/llms.txt` and `/AGENTS.md` for context injection into LLM prompts and developer workflows.

### 3. OAuth2 Social Login Integration
- **Social Providers**: Integrated OAuth2 authentication flows for GitHub, Google, and Apple.
- **OAuth Callback & Session Resolution**: Automated token exchange, user identity extraction, state security verification, and account creation/session binding.
- **TUI & REST Management**: Configure client IDs, secrets, and provider toggles dynamically via the REST API or the `moul` TUI (Settings view).

### 4. Advanced SQLite Migration & Schema Engine
- **Non-Destructive Column Removal & Data Type Alterations**: Added support for safely dropping columns and mutating column data types dynamically via SQLite shadow table migrations.
- **M:N Junction Storage & Rule Evaluator**: Clarified junction table layout for many-to-many relations and standardized expression evaluator syntax for dynamic access control (`@request.auth.id`).

### 5. Infrastructure & Operations
- **Daemon Binary Rename**: Renamed binary executable from `moul-dev` to `mould` for clarity (`mould` = daemon process, `moul` = TUI client).
- **Systemd Integration & Service Updater**: Added native `install-with-systemd.sh` script and atomic binary self-update handling for background Systemd daemons.
- **Toolchain**: Upgraded build toolchain requirement to Go 1.26.5.
